Projeto desenvolvido em Python para realizar uma análise exploratória da base de dados Varejo.csv

Foi feito: Carregamento e visualização das informações da base.
Verificação de valores nulos, duplicatas e inconsistências.
Limpeza dos dados e ajuste dos tipos de dados.
Análise estatística da quantidade de filhos dos clientes.
Agrupamentos por gênero e categoria de produto utilizando groupby().

Foram usadas as tecnologias: Python, Pandas e VSCODE.

INSTRUÇÕES: 
1. Baixe o arquivo Varejo.csv (Kaggle: base-varejo, de namespaiva)
2. Coloque o arquivo Varejo.csv na mesma pasta deste script
3. Rode este script no VSCode ou no Google Colab
 
Bibliotecas necessárias: pandas e numpy
